# TGT
An open-source monolithic VLIW core design with integrated NPU.
## Hardware Specifications (SuperCore Monolithic)
*   **Bus Width**: 2048-bit Mini-VRAM Interface[cite: 2]
*   **Architecture**: Ultra-VLIW (512-bit instruction slots)[cite: 2]
*   **AI Acceleration**: Integrated NPU 80P (64x64 Matrix Engine)[cite: 2]
*   **Power Target**: 100W Dynamic Scaling[cite: 2]
